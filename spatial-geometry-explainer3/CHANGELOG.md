# Changelog

## v2.1 General — 去专项内容的可迁移性测试版

### 实质性变化

- 移除先前针对单个课题的完整推导、示例网页与数字答案；不在 Skill 内保存该课题的名称、符号、参数或结果。
- 使用纯数学正交投影案例替换专用的角度/步骤视觉验收 JSON。
- 用通用向量运算回归替换领域专用数学脚本，覆盖点积、正交、重构、符号翻转、旋转及零向量边界。
- 将步骤验证由特定的固定编号改为任何连续步骤 `i→i+1`。
- 将 `source_relationship` 扩展为 `derived / copied / transformed / recombined / new-input`；只有 `copied` 严格要求源身份不变。
- 对不含角的合法课程允许空 `angles`；若 `requires_angles=true` 则继续实施角度可见性合同。
- 更新 `SKILL.md`、所有被专项示例污染的 reference 文档、README 和本日志。

### 不变的能力

- 量的来源/操作账本、角的真射线和原位测点、相邻步骤连续性、二维/三维融合、3D 相机与手机测试、截图帧审查、对抗参数检查。
- 原始中性 HTML 模板和来源账本 JSON 保留；Skill 目录名及主入口 `SKILL.md` 保持一致。

### 验收口径

- 包级脚本 PASS 证明格式和自带通用样例正确，不证明未来任一领域课件的画面或科学推导自动通过。
- `scripts/capture_lesson_frames.py` 可截真实帧，仍须人工识别角边与步骤交接。
- 如果独立测试要求避免任何旧题目泄漏，应在测试新对话中只提供该版本和统一提示，不引用已完成的旧课件。
