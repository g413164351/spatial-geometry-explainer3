# 连续、可核对的互动课件故事板

## 先明确学习者的起点

用户说“看不懂”“步骤不相连”时，不要第一反应增加公式：先问自己是否**画出了来源、参考、变换和结果之间的可见桥梁**。如果原始向量还没有定义清楚，就别讲分量公式。如果从 2D 分解图跳到 3D 局部法线，中间必须有动画或牵引线把同一分量带过去。

## 单元测试式故事板

每步用下面六列填写。不存在固定步数，**宁可插入过渡阶段，不可省略数学动作**。

| 字段 | 需要写出的内容 |
|---|---|
| 当前疑问 | 例如“输入向量是什么”“θ 在哪个平面” |
| 之前保留 | 前几步哪些箭头、角弧/参考线仍可认 |
| 此步动作 | 从哪个既有量经由哪个**明确运算**得到新量 |
| 几何证据 | 轴、法线、相应平面、角弧、直角符号、闭合关系 |
| 公式与读法 | 公式中每个系数对应图上哪条边、哪根轴 |
| 连贯实验 | 拖动阶段进度的五帧，以及零值/反向时预测什么 |

## 可复用的七阶段故事（可按任务删减或增加步骤）

1. **原对象与原矢量**：一根可指认的 `v`（速率/受力/电场等）加上单位与朝向；学员能说清楚是谁的向量。
2. **定义测角**：添加目标轴 `e` 与有方向的角弧 `θ`，两边属于同一平面。保持 `v` 原样。
3. **第一次分解**：`v_parallel=(v·e)e` 与 `v_perp=v-v_parallel` 出现，构成 `v` 的闭合直角三角形；先看图，后出现公式。
4. **复制到新目标**：由同一个 `v_perp`（或任务要求的上一阶段分量）生成一个保持方向与长度的透明副本，沿可见路径平移到不同表面/坐标轴/测量点。
5. **第一个目标投影**：画它自己的局部轴/法线，`v_n=(v·n)n` 和切向分量，闭合三角形；标有符号投影的朝向。
6. **第二个目标投影**：保留第一个三角形的结果，给第二个对象做一模一样的运算；显式展示两对象法线为何不同。
7. **合并与验证**：按需要合成各贡献或预测物理效果；参数归零/反号，要求学员先预测再观看动画。

注意：如果第一阶段是三维非水平向量，先画它到水平面的投影，再画水平分量与侧向分量；相应增加一个阶段。不能把三维非共面输入直接代入二维正弦/余弦公式；应先声明测角平面并完成需要的投影。

## 每个阶段的文案模板

> **你现在看到**：蓝色箭头是第一阶段定义的数学向量。  
> **我们做了什么**：把它复制到目标 A、B 处，仅移动显示锚点，方向与长度没有变。  
> **为什么要这样做**：A、B 的局部参考方向不同，接下来分别投影，比较同一输入在不同坐标轴中的分量。

这三句内容比“观察两个结果不同”更有帮助，因为它包含**从哪里来、做了什么、为什么做**。

## 相机、局部放大与公式的联系

- **相机**：先在全局视角认识对象；必要时平滑转到测角平面，但不改变矢量数据。不允许在画面空白处突然替换成另一个坐标系统。
- **放大窗**：先闪烁原位锚点，再沿引线“展开”局部放大窗；窗口标题写“由目标 A 测点放大 / 局部截面”，同时保留完整模型供辨认。
- **公式**：它是屏幕图的**索引**：每项高亮能回查源箭头和测角弧。先展示操作，再出现数学结论；引号中的概念词不要代替数学定义。
- **动画**：允许双向拖动进度条，在 0/25/50/75/100% 皆可暂停；复制期间旧箭头可变透明，但新箭头必须沿路来、长度方向不变。

## 何时必须引入新步骤

如果出现以下任一情况，强制再加一阶段：新物理量未定义；新角测量平面不同；需要把结果换到另一物体的局部坐标；原分量会被复制到其他锚点；两个分量需要合成；局部量需要物理模型才能推到力矩/电流/运动等下游结果。反过来，只有明显多余且没有新运算的阶段才能合并。

## 自测：本网页是否真的能教学？

让一个不读辅助说明的人完成：

1. 在当前图指认 `v` 的来源、单位和所用参考系。
2. 点击 `sinθ`，指出**哪一个角**和哪一条对边。
3. 在下个对象出现时，倒回进度条，指出箭头从**哪里复制来**。
4. 指出两个局部法线分别在哪里，以及正负号来自哪个点积。
5. 把角设零/反向，预测哪些分量消失或反向，并验证。

答不出来的地方就是要补图或补过渡的地方。


## 新增：角度教学与视觉上的“真假保留”

- 当学习者问“这个角是哪两根线”时，必须先回答**实物结构线还是向量方向线**，再说原位顶点、两条方向射线、同一测角平面、角弧；值和颜色最后出现。
- 双对象比较时，第一对象的图形必须在第二对象加入期间可辨认：**文本中保留 ≠ 图形中保留**。
- 局部剖面不能脱离主体出现，要从模型上的原位测点引出，显示从哪里看；小角度若形状夸大，需要显式写“演示放大”。
- 学生能不读说明，在上一步和下一步的并排截图中指出保留、新增、运算；否则插入桥接步骤。
- 对于零基的程序状态，明确规定 UI 第 i 步对应 `stage===i-1`（若 UI 自 1 编号）；检查每一步首帧、末帧是否符合故事板。
