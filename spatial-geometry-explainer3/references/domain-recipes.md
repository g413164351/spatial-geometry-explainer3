# 跨领域迁移配方：保留“来源→运算→结果”的骨架

不要把任何一个领域的具体公式换个字母就套入其他领域。每次先定“哪些是自由矢量、哪些绑定作用点/坐标系”，再选适用的运算。即使研究对象没有实体（如基向量、导航方位），也保留原量身份和可见的衔接。

## 1. 通用平面/空间向量分解（数学、物理入门）

- **输入**：一根原矢量 `v` 和方向单位矢量 `e`，`θ` 是两者所在平面内的夹角。
- **连续动画**：只画 `v` → 原位画 `e` 与 θ → 从 `v` 端点垂线到 `e` → `v_∥=(v·e)e` 与 `v_⊥=v−v_∥` 闭合 → 拖动 θ 演示正/负/零。
- **注意**：`|v|sinθ` 可能是长度，`v·e` 是有符号标量，不要混叫“方向向量”。
- **迁移**：力、速度、位移、电场、磁场、空间几何皆可以复用操作链。

## 2. 斜面力学：重力如何拆成沿面和法向分量

- **身份**：倾角 θ 的斜面、滑块质心 `P`、重力 `F_g=mg` 向下，局部切线 `t` 指向下坡、法线 `n` 指离开斜面。
- **连续动画**：先显示同一根重力 `F_g` → 画斜面 θ 与局部基底 → 在质心原位分解 `F_t=(F_g·t)t` 和 `F_n=(F_g·n)n` → 保留原点、形成直角三角形 → 标明 `|F_t|=mg sinθ`, `|F_n|=mg cosθ`。
- **注意**：`F_g·n` 在 `n` 指离开斜面时为负；法向接触力的方向另算，绝不能把重力的“法向分量”和“地面支持力”当成同一个作用力。
- **反证**：θ=0 时沿面重力为 0；角度加大沿面分量增大。

## 3. 电磁学：同一电场对不同方向的导线/平面投影

- **输入**：给定均匀电场 `E` 的方向、单位 `V/m`，两片不同朝向的表面 `S_A`,`S_B` 及各自法线 `n_A`,`n_B`。
- **连续动画**：先定义 E（场矢量）→ 复制**统一电场假设下的同一 E** 到两表面测量点 → 各自画表面法线 → 逐个展示 `E·n` 的有符号投影与三角形 → 对比正/负号。若进一步讲通量，再明确 `Φ=∫_S E·n dA`；均匀、平面、小面元时才可写 `Φ=(E·n)A`。
- **注意**：非均匀场不同点 E 可能不同，不能做无条件“等长副本”；通量与电场分量单位不同。

## 4. 机械臂：关节转速怎样贡献末端速度

- **输入**：基座、连杆、关节 `J_i`，角速度 `ω_i` 沿转轴，关节世界位置 `o_i`，末端点 `p`。
- **连续动画**：画 `ω_i` 的旋转轴与角弧 → 画 `r_i=p−o_i` → 引出叉积 `v_i=ω_i×r_i` 并画真实末端方向 → 在末端**原位平移展示多关节贡献** `v_1,v_2,...` → 首尾相接得 `v_end=Σv_i` → 引出雅可比 `J(q)qdot`。
- **注意**：关节角速度与末端线速度不在同一量纲，不能只是把 ω 箭头复制到末端宣称它是线速度；每一步要展示叉积操作。锁住其余关节、令单一 `ω_i=0` 是基础测试。

## 5. 运动平台与移动介质：相对速度与合成

- **输入**：相对于运动参考系的速度 `v_relative`、参考系自身的速度 `v_medium`、世界系中的速度 `v_ground`。
- **连续动画**：先定义介质参考系与世界参考系 → 两根速度箭头首尾相接 → 地速 `v_ground=v_relative+v_medium` → 画参考轴与结果方向的夹角 → 调整参考系速度、显示角度和合成结果变化。
- **注意**：速度的参考系必须明示；不可将物体相对速度与参考系速度的方向定义混用。

## 6. 刚体姿态与计算机图形学：世界矢量、局部矢量、相机观察

- **输入**：一个世界固定矢量 `v_world`、旋转的对象局部坐标系 `B` 和相机 `C`。
- **连续动画**：先定义三套坐标轴 → 让对象真的旋转，`R_BW` 随姿态更新 → 保持世界箭头原位 → 观察 `[v]_B=R_BW v_world` 的三个**坐标分量**如何改变 → 单独转动相机只改变观察角度、不改变世界值或局部值。
- **注意**：画“坐标值改变”的图不能把世界矢量偷偷跟随物体旋转；对象旋转与相机旋转是两种操作。

## 7. 力矩、杠杆和运动规划

- **输入**：真实作用力 `F` 在作用点 `p`，选定参考点/旋转轴 `o`，位矢 `r=p−o`。
- **连续动画**：先画作用点与 F → 从 o 画 r（而不是从任意零点乱画）→ 显示 r 与 F 张成的平面、力臂/夹角 → 法向用右手定则标 `τ=r×F` → 对比 F 方向、作用点变化。需要把力箭头平移到新点作**数学展示**时必须提醒其物理力矩可能改变。
- **反证**：r∥F 时 τ=0；力臂改变会改力矩大小；F 反向会使 τ 反向。

## 8. 非矢量领域的借用方式（例如数据流程、算法、因果图）

可以复用**状态来源追踪**：输入数据 ID → 规则/过滤/聚合 → 输出数据 ID → 解释关键差异，步骤之间用持续高亮、复制/移动或连线连接。
但不要强行为数据字段画单位法线、角弧或三维点积，更不能把“算子输出”描述为物理矢量。按领域量的真实语义替换运算链。
