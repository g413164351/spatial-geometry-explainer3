# 数学基准：坐标、向量与投影

## 1. 开始任何 3D 推导前写出几何账本

- 世界坐标 `(x,y,z)`、左右手系；对象局部坐标原点和基向量；相机坐标只用于渲染，不能代替物理坐标。
- 正方向、正角定义、旋转轴及单位（长度、速度、角度）；角度显示可用度，但三角计算应将度转换为弧度。
- 每个量属于：向量、单位法线、**带符号**标量投影、向量投影、绝对长度、方位角或二维平面内角。
- 测角方法：先给出角的两个参考向量 `a,b`，再给角弧所在平面；`θ=acos(clamp(a·b/(|a||b|),-1,1))`。需要正负方向时用参考法线 `k` 和 `atan2(k·(a×b),a·b)`。

## 2. 真正能画出来的向量运算

对速度（或位移、力）`v` 与单位法线 `n`：

```text
标量法向分量：v_n = v · n
向量法向投影：v_perp = (v · n) n
向量切面投影：v_parallel = v - (v · n) n
重构：v = v_parallel + v_perp
```

绘图时将同一原点 `p` 上的 `v` 与投影箭头放在一起，用虚线或直角标记联系其端点；需要在多个锚点显示同一自由矢量时，仅对教学副本做平移，不凭目标的旋转改变原自由矢量。

若任务定义局部正交坐标 `e1,e2,e3`，对任意 `v`：

```text
v1 = dot(v,e1), v2 = dot(v,e2), v3 = dot(v,e3)
v = v1 e1 + v2 e2 + v3 e3
```

只在基底正交且同参考系时，可以直接将上述标量点积当作分量；若基底不正交，则需要逆基或显式求解。局部二维角度必须先明确其测角平面及被投影的参考方向。

## 3. 刚体变换及原位锚定

- 同一部件所有测量对象共用局部→世界变换：`p_world = R p_local + t`。
- 方向向量与法线做旋转 `v_world=R v_local`；**不对方向做平移**。
- 法线的符号由选定朝外一侧的约定确定；左右镜像零件法线不应简单复制。
- 转轴过世界点 `o`、单位向量 `k` 时：`p' = o + R_k(θ)(p-o)`。使用同一变换更新物体几何、角弧、锚点与关节附着件，保证不会飘离。
- 视觉“放大角度差异”可对辅助角弧和标注使用倍数，但必须保留真实几何、计算值及清楚的“演示倍率≠真实角度”说明。

## 4. 机械臂/通用机构的推广

二维双连杆机械臂（在 x-y 平面，关节转轴沿 z）：

```text
p_end = (L1 cos θ1 + L2 cos(θ1+θ2),
         L1 sin θ1 + L2 sin(θ1+θ2))

v_end = J(θ) [θdot1, θdot2]^T
J = [ -L1 sin θ1-L2 sin(θ1+θ2), -L2 sin(θ1+θ2)
       L1 cos θ1+L2 cos(θ1+θ2),  L2 cos(θ1+θ2) ]
```

教学时按“旋转轴 → 各关节角弧 → 连杆位置 → 末端位置向量 → 每个关节运动贡献 → 矢量合成 → J”逐层显示；θ2 是两杆之间的**相对角**，不是第二杆对世界坐标的总角。三维机械臂改用齐次变换 `T_0i`、各关节轴的世界方向和末端雅可比，禁将二维推导偷换成任意 3D 情况。

## 5. 跨学科通用的“先算后画”验证与反例

- **自由矢量与作用点不同**：数学自由矢量 `v` 平移只变 `tail` 与 `tip` 的坐标偏置，不改变分量、模长和方向。点力 `F` 从 `p1` 物理移到 `p2` 时可能改变 `τ=(p-o)×F`；在动画里必须标成“仅比较投影的箭头副本”，或给出新作用点的完整力学解释。
- **向量投影与标量投影不同**：`v·n` 是有符号标量；`(v·n)n` 是带方向的投影矢量。辅助箭头若按教学倍率绘制，显示数值必须来自原始真实分量。
- **变化参考系 ≠ 变化物理矢量**：`[v]_B=R_{BA}[v]_A` 是对同一物理向量换基。相机从正视切到侧视时既不是对物体施力也不是对矢量换基（只是屏幕渲染观察）。
- **角需要同平面参照**：`|v|sinθ` 成立的前提是 `θ` 真的是该平面中 `v` 与所用参考轴之间的角（且对边的物理意义对应）。当输入在三维空间中不属于测角平面时，必须先投影、再量角，不得直接把总向量模长套入二维三角形。
- **投影重构测试**：对任意归一化 `n` 和向量 `v`，断言 `v≈(v·n)n+[v−(v·n)n]`，断言残余矢量与 `n` 正交。测试 `n→−n`、`v→−v`、`v·n=0` 以及非零大小以防仅偶然默认值正确。
- **三角形与屏幕投影**：三维中正交的两条边在任意投影相机的屏幕上未必呈直角；直角符号应定义在真实三维平面，或以注明的局部正交截面展示，不能为了画面方便画一个假的 90°。
